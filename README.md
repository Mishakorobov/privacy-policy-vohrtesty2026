**Политика конфиденциальности мобильного приложения «Билеты ВОХР тесты 2026»**

**1. Общие положения**
Настоящая политика составлена в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки данных пользователей приложения «Билеты ВОХР тесты 2026» (далее — Приложение).

**2. Обрабатываемые данные**
Приложение **не собирает, не обрабатывает и не передает** идентифицирующие персональные данные (ФИО, email, телефон, геолокацию) на удаленные серверы.

Вся техническая информация сохраняется исключительно локально в памяти мобильного устройства пользователя. К ней относятся:

* Текущий прогресс обучения (выбранные ответы, статистика ошибок).
* Пользовательские настройки (выбранная профессия, тема оформления интерфейса, параметры автоперехода).
* Локальный счетчик времени использования тем оформления.

**3. Интеграция со сторонними сервисами**
Приложение содержит внешнюю ссылку на сервис приема добровольных пожертвований (Яндекс Чаевые). При переходе по ссылке сбор и обработка платежных данных осуществляется на стороне сервиса-партнера в соответствии с его политикой конфиденциальности. Приложение не собирает и не имеет доступа к платежным реквизитам.

**4. Безопасность и управление данными**
Данные защищены стандартными механизмами операционной системы устройства. Пользователь может в любой момент полностью удалить все накопленные данные следующими способами:

* Воспользоваться кнопкой «Сбросить весь прогресс» в настройках Приложения.
* Очистить данные Приложения через системные настройки устройства.
* Удалить Приложение с устройства.

**5. Изменения политики**
Разработчик вправе вносить изменения в настоящую Политику. Новая редакция вступает в силу с момента ее обновления в Приложении.
