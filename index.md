# Политика конфиденциальности мобильных приложений «Билеты ВОХР тесты 2026» и «Частная охрана билеты 2026»

## 1. Общие положения

Настоящая Политика конфиденциальности составлена в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки информации пользователей мобильных приложений «Билеты ВОХР тесты 2026» и «Частная охрана билеты 2026» (далее — Приложение).

## 2. Обрабатываемые данные

Приложение не собирает, не хранит и не передает на удаленные серверы разработчика идентифицирующие персональные данные (ФИО, номер телефона, геолокацию, биометрию, списки контактов).

Вся пользовательская информация хранится исключительно локально в памяти устройства (`SharedPreferences`):

* **Прогресс обучения:** сохраненные ответы на вопросы, позиции прохождения тестов, список вопросов с ошибками («Работа над ошибками»), накопленная статистика ошибок по каждому вопросу.
* **Настройки интерфейса:** выбранный профиль обучения (ВОХР / Частный охранник), цветовая схема оформления, статус функции автоперехода к следующему вопросу.
* **Технические параметры сессии:** суммарное время использования Приложения и кастомных тем, флаги демонстрации диалоговых окон (поддержка проекта, предложение оценки).

## 3. Сторонние сервисы и внешние вызовы

* **RuStore Review SDK (ООО «ВК»):** Приложение использует библиотеку `flutter_rustore_review` для отображения нативного окна оценки. Взаимодействие с сервисом регулируется пользовательским соглашением и политикой конфиденциальности платформы RuStore.
* **Сервис пожертвований (Яндекс Чаевые):** переход осуществляется через внешний браузер по ссылке. Приложение не имеет доступа к банковским картам и платежным реквизитам пользователя.
* **Обращение в службу поддержки:** инициируется через почтовый протокол `mailto:` в установленном на устройстве почтовом клиенте. Адрес электронной почты пользователя и текст сообщения передаются разработчику только при добровольной отправке письма самим пользователем.

## 4. Управление и удаление данных

Пользователь может в любой момент полностью или частично удалить локальные данные:

* Сбросить прогресс разделов или общий прогресс через меню «Настройки».
* Очистить накопленную аналитику ошибок через кнопку сброса в разделе «Статистика».
* Полностью стереть всю информацию через системные настройки устройства (пункт «Очистить данные приложения») либо удалив Приложение.

## 5. Изменения политики

Разработчик оставляет за собой право обновлять настоящую Политику при добавлении нового функционала. Актуальная редакция публикуется внутри Приложения.
